# DataGraphs operating contract

Read `docs/CONTINUITY.md`, then the founder correction in `docs/FOUNDING_RECORD.md`, before planning or changing product behavior.

The founder's explicit direction on 9 September 2026 supersedes the CSV-first product doctrine. DataGraphs collects permitted internet data, builds maintained, evidence-backed graphs of entities and relationships, and uses those graphs to power intelligence products. CSV upload/analysis may remain a demonstration; it is not the business or a prerequisite for building the collection engine.

Optimize for the new proof: source acquisition -> evidence-backed observations -> entity resolution -> graph relationships -> change detection -> useful intelligence delivered to a buyer. Do not reinterpret graph to mean only a chart, analytics envelope, transcript, or vector index. Do not pick an unvalidated pilot market and silently make it the permanent company mission.

Preserve existing application code and deployed services unless a task explicitly changes them. Reuse proven identity, provenance, validation, and deterministic computation where appropriate, without forcing the web graph into the old CSV schema. Do not claim old analytics tests validate a crawler or knowledge graph that does not yet exist.

Keep observations, source assertions, inferred relationships, and calculated values distinguishable. AI extraction and entity matching are fallible; require evidence, validation, reversible correction, and explicit uncertainty. No arbitrary model-generated execution. Apply source permissions, acquisition limits, and personal-data minimization. Never bypass access controls or commit secrets.

Use owned implementations, suitable open-source components, authorized no-cost sources and small approved Cloudflare infrastructure spend. No additional paid external service is an assumed dependency. No uncontrolled crawling, inference, or automatic spending upgrades.

Record operational truth in `docs/PROJECT_STATE.md` and consequential decisions in `docs/DECISIONS.md`. For code changes run `npm test`, `npm run check`, and `npm run build`; disclose tests or runtime checks not performed. Preserve historical records and never fabricate deployment evidence.
