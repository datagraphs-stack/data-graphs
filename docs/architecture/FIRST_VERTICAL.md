# First vertical architecture

exact CSV bytes → SHA-256 source identity → preserved row strings → profile + declared semantics → untrusted intent interpretation → clarification when material → validated `AnalysisPlan` → deterministic result + execution trace → content-addressed revision → versioned DataGraph envelope → table/chart + trace-driven Verify UI.

`src/engine.js` owns parsing, profiling, validation, and execution; it has no DOM dependency. `src/semantics.js` declares the canonical metric policy. `src/intent.js` defines the intent-provider boundary and deterministic proving adapter. `src/app.js` orchestrates clarification and presentation but cannot calculate authoritative values. Candidate interpretations are untrusted; `NEEDS_CLARIFICATION` never executes.

Current operations: equality/inequality filtering; dimensions; ISO calendar-month/year bucketing; fixed-point decimal sum/min/max; count/average; sorting; result limit; and latest-year top-N with previous-calendar-year comparison. Trace version 1 records execution facts and drives Verify. DataGraph schema version 1 retains exact base64 source bytes plus SHA-256, profile and semantic hashes, questions/interpretations, validated plans, traces, result hashes, visualization, warnings, and content-addressed parent revisions under a distinct entity ID. Validation and recomputation expose tampering. Missing: durable persistence/reload/share, server custody, bounded model intent, and an average/percentage rounding policy.
