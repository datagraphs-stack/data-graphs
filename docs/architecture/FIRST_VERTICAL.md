# First vertical architecture

exact CSV bytes → SHA-256 source identity → preserved row strings → profile + declared semantics → untrusted intent interpretation → clarification when material → validated `AnalysisPlan` → deterministic result + execution trace → content-addressed revision → versioned DataGraph envelope → table/chart + trace-driven Verify UI.

`src/engine.js` owns parsing, profiling, validation, and execution; it has no DOM dependency. `src/semantics.js` declares the canonical metric policy. `functions/api/intent.js` asks Workers AI only for bounded intent slots; `src/intent.js` deterministically compiles and validates those untrusted slots. Its keyword adapter is test-only. `src/app.js` orchestrates clarification and presentation but cannot calculate authoritative values. Candidate interpretations are untrusted; `NEEDS_CLARIFICATION` never executes.

Current operations: equality/inequality filtering; dimensions; ISO calendar-month/year bucketing; fixed-point decimal sum/min/max; count/average; sorting; result limit; and latest-year top-N with previous-calendar-year comparison. Trace version 1 records execution facts and drives Verify. DataGraph schema version 1 retains exact base64 source bytes plus SHA-256, profile and semantic hashes, questions/interpretations, validated plans, traces, result hashes, visualization, warnings, and content-addressed parent revisions under a distinct entity ID. Validation and recomputation expose tampering. D1 preserves and reloads the complete envelope through stable public-link routes. Remaining limitations include authentication/private sharing, broader intent and operation coverage, production abuse controls, and an average/percentage rounding policy.
