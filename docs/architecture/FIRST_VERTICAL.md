# First vertical architecture

`public/orders.csv` → `parseCsv` → preserved row strings → `profileDataset` + declared semantics → untrusted intent interpretation → clarification when material → `AnalysisPlan` candidate → structural/semantic validation → `executePlan` → result rows plus evidence → table/chart and Verify UI.

`src/engine.js` owns parsing, profiling, validation, and execution; it has no DOM dependency. `src/semantics.js` declares the canonical metric policy. `src/intent.js` defines the intent-provider boundary and deterministic proving adapter. `src/app.js` orchestrates clarification and presentation but cannot calculate authoritative values. Candidate interpretations are untrusted; `NEEDS_CLARIFICATION` never executes.

Current operations: equality/inequality filtering; dimensions; ISO calendar-month/year bucketing; fixed-point decimal sum/min/max; count/average; sorting; result limit; and latest-year top-N with previous-calendar-year comparison. Plans carry version 1 and are structurally and semantically validated before execution. Evidence records source and filtered/result counts, columns, an immutable plan snapshot, arithmetic policy, warnings, and engine version. An all-blank metric group remains explicitly unknown rather than becoming zero. The Studio preserves deeply frozen revision snapshots during the session and exposes the founding follow-up as a second validated plan. Missing: source hashing, an average/percentage rounding policy, durable revision persistence/share, cross-session lineage, and server custody.
