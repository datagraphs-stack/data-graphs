# DataGraphs operating contract

Read `docs/CONTINUITY.md` before changing product behavior. Optimize for evidence toward the first perfect DataGraph, not activity. Preserve the trust boundary: AI may propose a validated plan; only deterministic code computes authoritative values. Unknown and ambiguity must remain visible. Update `docs/PROJECT_STATE.md` when operational truth changes, add consequential architecture changes to `docs/DECISIONS.md`, run `npm test`, `npm run check`, and `npm run build`, and never commit secrets or fabricate deployment evidence.
