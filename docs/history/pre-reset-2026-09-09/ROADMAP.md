# Dependency roadmap

Progress is reduced distance to **one perfect DataGraph**, not output volume.

1. **Foundation and source evidence** (`advancing_core`): establish durable intent, a runnable Studio shell, deterministic commerce fixture, CSV parsing, conservative profiling, and source identity. Exit when exact fixture behavior is tested and a stranger can inspect an uploaded dataset.
2. **Authoritative computation** (`advancing_core`): mature the constrained plan schema, schema/semantic validation, decimal policy, filters, date buckets, grouping, aggregations, sorting, top-N, and previous-year comparison. Exit on known-answer and edge-case values—not chart existence.
3. **Answer and evidence** (`advancing_core`): render declared result shapes and make Verify reconstruct source, semantics, operations, counts, warnings, plan, and runtime identity. Exit when presentation demonstrably matches engine output.
4. **Bounded intent and revision** (`advancing_core`): place natural-language interpretation behind the validation boundary; clarify ambiguity; revise plans immutably; recompute. Exit when both canonical prompts work without arbitrary execution.
5. **Persistence and staging proof** (`advancing_core`): persist source/version/plan/result/evidence, stable share route, deploy Cloudflare staging, and record Git-to-runtime receipt. This completes the founding proof.
6. **Evidence-led expansion**: reassess user evidence before richer operations, Excel, multi-table joins, semantic metrics, workspaces, live connectors, scheduled refresh, narratives, collections/dashboards, signals, collaboration/certification, agent/API/MCP surfaces, enterprise controls, and billing.

Work on later stages while an earlier exit is unmet is `drift_risk` unless it directly unblocks that exit.
